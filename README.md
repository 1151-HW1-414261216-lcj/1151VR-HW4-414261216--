本專案使用 Unity 6 開發 3D 飛行遊戲。首先刪除第三方套件不相容的舊腳本，並將 Project Settings 中的 Active Input Handling 切換為 Both 以支援鍵盤控制。接著撰寫 FlightController 腳本實作自動前進與鍵盤上下左右移動，並將攝影機設為飛機子物件達成跟隨視角。音效部分以雙 AudioSource 處理循環引擎聲與單次音效，最後於 Obstacle 物件配置實體 Mesh Collider 與勾選 Is Trigger 的感應 Box Collider，成功實現碰撞撞擊聲與順利穿越時的通過音效。
